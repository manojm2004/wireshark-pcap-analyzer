# 🔍 CEH Network Forensics & Wireshark Threat Inspection Suite

A cybersecurity forensic analysis toolkit aligned with the **EC-Council Certified Ethical Hacker (CEH)** curriculum (Sniffing, Traffic Analysis & IDS Evasion).

## 📌 Roadmap Alignment: Networkers Home Cyber & Cloud Security
- **Domain:** CEH (Certified Ethical Hacker) & AI-SOC Threat Detection
- **Core Capabilities:**
  - Automated detection of Nmap port scanning patterns (SYN, Null, XMAS)
  - Extraction and identification of unencrypted credentials over legacy protocols (HTTP, FTP, Telnet)
  - Deep packet inspection for SYN Floods and ARP Cache Poisoning (MitM)
  - Comprehensive reference manual of production Wireshark display filters

## 📁 Repository Structure
- `scripts/ceh_attack_detector.py`: Automated threat extraction tool for `.pcap` files.
- `ceh_packet_forensics_guide.md`: Complete reference cheat sheet for Wireshark display filters and packet decoding.
- `pcap_analyzer.py`: Protocol summary and 3-way handshake health checker.
